# Developer tools

Code, docs, and workflow MCP servers. Full list index: [README](../README.md).

- [Context7](https://plugmcp.ai/mcp?q=context7) · [repo](https://github.com/upstash/context7) — up-to-date library docs for agents
- [Serena](https://plugmcp.ai/mcp?q=serena) · [repo](https://github.com/oraios/serena) — semantic code retrieval and edit
- [git-mcp](https://plugmcp.ai/mcp?q=git-mcp) · [repo](https://github.com/idosal/git-mcp) — remote MCP for any GitHub project
- [codebase-memory-mcp](https://plugmcp.ai/mcp?q=codebase-memory) · [repo](https://github.com/DeusData/codebase-memory-mcp) — local code graph for agents
- [Desktop Commander](https://plugmcp.ai/mcp?q=DesktopCommander) · [repo](https://github.com/wonderwhy-er/DesktopCommanderMCP) — terminal and files for Claude
- [n8n-mcp](https://plugmcp.ai/mcp?q=n8n-mcp) · [repo](https://github.com/czlonkowski/n8n-mcp) — build n8n workflows from the agent
