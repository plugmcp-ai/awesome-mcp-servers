This list is the human-curated shelf. PlugMCP indexes the full ecosystem; this repo keeps the ones agents actually use.

## Why this list

- Each entry links back to its PlugMCP page (install, tools, host option) and the publisher repo.
- Shelves match the public directory: browser, databases, design, security, and the rest.
- We skip star-farm mirrors and empty forks. Prefer the official or clearly maintained server.

## Install a server

1. Open the PlugMCP page from a link above.
2. Use **Add to Cursor**, **Claude**, or **VS Code**, or copy the publisher snippet.
3. Or choose **Run on PlugMCP** to host a copy with keys and call logs.

## Contributing

Open a PR that adds one server or skill:

1. It should already appear on [plugmcp.ai](https://plugmcp.ai/mcp), or include a [submit](https://plugmcp.ai/mcp/submit) link.
2. Prefer the official publisher URL.
3. Put it under the right shelf. Keep the blurb to one line.
