# Weekly picks cadence

Keep the shelf alive with a small, regular commit. Do not dump the full PlugMCP directory.

## Every week

1. Check [plugmcp.ai/new](https://plugmcp.ai/new) and [plugmcp.ai/trending](https://plugmcp.ai/trending).
2. Pick at most 3–5 additions that pass [CONTRIBUTING.md](../CONTRIBUTING.md).
3. Update the matching `servers/*.md` file and `catalog/servers.json`.
4. Commit message style: `Add weekly picks: <names>`.
5. Optional: open a GitHub Discussion summary titled `Weekly picks — YYYY-MM-DD`.

## External lists

After the shelf has a clear structure, submit this repo as a related link to major awesome-MCP lists (do not paste the whole catalog into them):

- https://github.com/punkpeye/awesome-mcp-servers
- https://github.com/appcypher/awesome-mcp-servers
- https://github.com/wong2/awesome-mcp-servers

Point reviewers at the PlugMCP install path and the curated shelf files under `servers/`.
